## 🎨 Customization Options

Want to adjust colors? Edit `tailwind.config.ts`:

```typescript
colors: {
  accent: "#00d4ff",      // Change cyan color
  accentGold: "#ffd700",  // Change gold color
  primary: "#0a0a0a",     // Change dark color
}
```
